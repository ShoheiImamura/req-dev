## 備品：コレクション → シングル

```plantuml 備品一覧（コレクション）と備品詳細（シングル）
@startsalt
{+
  {* 備品 | 貸出 | 社員 }
  {
    {
      "検索: [          ]"
      {#
        名称           | 種類     | 保管場所 | 状態
        プロジェクターA | 映像機器 | 3F 倉庫  | 貸出中（田中 9/22）
        ノートPC-03     | PC       | 2F 棚    | 貸出可
        HDMI ケーブル   | 小物     | 2F 棚    | 貸出可
      }
    } | . | {
      == ノートPC-03
      種類: PC
      保管場所: 2F 棚
      状態: 貸出可
      --
      [ 借りる ] [ 編集 ]
      --
      貸出履歴
      {#
        貸出日 | 社員 | 返却日
        9/1    | 鈴木 | 9/5
      }
    }
  }
}
@endsalt
```

## 貸出：コレクション（自分の貸出／全員の貸出）

```plantuml 貸出一覧（コレクション）
@startsalt
{+
  {* 備品 | 貸出 | 社員 }
  {
    ( ) 自分の貸出  (X) 全員の貸出   [ ] 期限超過のみ
    {#
      備品           | 社員 | 貸出日 | 返却予定日 | 状態
      プロジェクターA | 田中 | 9/15   | 9/22       | 貸出中
      ノートPC-01     | 佐藤 | 9/1    | 9/8        | <b>期限超過</b>
    }
  }
}
@endsalt
```

## ビューの構成

| オブジェクト | コレクション | シングル | 呼び出し元 |
|---|---|---|---|
| 備品 | 備品一覧（検索・絞込） | 備品詳細（貸出履歴つき） | ナビ / 貸出一覧の備品名 |
| 貸出 | 貸出一覧（自分／全員／超過） | 貸出詳細 | ナビ / 備品詳細 |
| 社員 | 社員一覧（総務のみ） | 社員詳細（貸出中一覧） | 貸出一覧の社員名 |
