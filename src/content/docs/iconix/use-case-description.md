## 基本コース

1. 社員は **備品一覧画面** で借りたい備品を探す。
2. システムは備品の所在と貸出可否を表示する。
3. 社員は備品を選び、**備品詳細画面** で「借りる」を押す。
4. システムは **貸出** を作成し（借用者 = 社員、返却予定日 = 当日 + 7 日）、備品の所在を「借用者」として表示する。
5. システムは貸出完了を表示する。

## 代替コース

- 3a. 備品がすでに貸出中の場合、システムは借用者と返却予定日を表示し、「借りる」を無効にする。
- 4a. 社員が返却予定日を変更した場合（要確認）、システムは上限（14 日）を超えていないか確認する。

画面名は OOUI のビュー、情報名は情報モデル／ドメインモデルと揃える。手順の検証はロバストネス図へ渡す。
